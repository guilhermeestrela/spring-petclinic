## Complementos identificados na conferência final

- 🟢 Há **.devcontainer/Dockerfile**, usado pelo Gitpod conforme comentário e .gitpod.yml. Não é Dockerfile de empacotamento da aplicação. .devcontainer/devcontainer.json usa imagem/features distintas, incluindo Java 21 Oracle, enquanto o build da aplicação declara Java 17. Estes arquivos de ambiente não receberam spec detalhada; permanecem n/a na matriz, com este contexto.
- 🟢 MySqlIntegrationTests usa perfil mysql, Testcontainers mysql:9.7 e pode ser desabilitado sem Docker; PostgresIntegrationTests usa Compose e assumption de Docker. Ambos têm findAll que chama repository duas vezes, com comentário served from cache, mas sem assert direto de hit/miss. ownerDetails espera HTTP 200.
- 🟢 PetClinicIntegrationTests tem expectativas de 200 para detalhe/lista e chamadas repetidas do repository. MysqlTestApplication é launcher de desenvolvimento/teste, não módulo funcional novo. Nenhuma dessas classes foi executada aqui.
- 🟢 PostgresIntegrationTests.PropertiesLogger enumera propriedades no launcher; isso é código de teste, não prova de telemetria de produção. Valores de ambiente reais não foram coletados.
- 🟡 Fontes SCSS/CSS, fontes/imagens, configurações de editor, licença, políticas de contribuição, setup auxiliar de banco e plano JMeter são inventariados, sem spec individual completa. Manter n/a evita atribuir cobertura semântica inexistente.
